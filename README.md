# Курсовой Проект: Цифровой двойник энергетической установки (Вариант A30)

## Этап 1. Назначение программы

Программа моделирует цифровой двойник технологического процесса — энергетической установки.
Она получает показания датчика мощности, преобразует их в индикатор состояния процесса \(Q\), выполняет оперативный контроль накопленного отклонения (Тип С) и проводит статистический анализ данных.

## Этап 2. Алгоритм работы программы

1. Программа инициализирует константы: целевое значение \(Q_0 = 350\) и максимальное допустимое отклонение \(S_{max} = 1500\).
2. Программа циклически читает показания датчика \(X\) до тех пор, пока пользователь не введет недопустимый символ (признак конца ввода).
3. Каждое \(X\) преобразуется в индикатор \(Q\) по кусочно-заданной функции и сохраняется в массив (для последующего поиска медианы).
4. Выполняется контроль: расчет накопленного отклонения \(S_i = S_{i-1} + |Q_i - Q_0|\) и поиск **первого** превышения \(S_{max}\).
5. Выводится текущее состояние процесса (норма / тревога) с указанием деталей при первом превышении.
6. После завершения ввода вычисляется полная статистика по массиву значений \(Q\).

### Организация данных

| Данные | Назначение | Структура |
|--------|------------|-----------|
| X | текущее показание датчика | `double` |
| Q[ ] | массив значений индикатора | `double` |
| Q₀ | целевое значение (константа 350) | `double` |
| S_max | порог накопленного отклонения (1500) | `double` |
| s_current | текущее накопленное отклонение | `double` |
| alarm_found | флаг первого превышения (0/1) | `int` |
| n | количество обработанных значений | `int` |

### Математическая модель и пример расчёта

$$
Q(x) = \begin{cases}
2x + 10, & x < 100 \\
1.5x + 60, & 100 \le x < 200 \\
0.8x + 200, & x \ge 200
\end{cases}
$$

| X | Ветка | Расчёт | Q |
|---|-------|--------|---|
| 50 | x < 100 | 2·50 + 10 | 110 |
| 150 | 100 <= x < 200 | 1.5·150 + 60 | 285 |
| 250 | x >= 200 | 0.8·250 + 200 | 400 |

### Алгоритм контроля и его результаты

Контроль типа C: поиск первого превышения накопленного отклонения \(S_{max}\). 
Формула расчёта: \(S_i = S_{i-1} + |Q_i - Q_0|\).

**Возможные состояния:**

| Условие | Состояние |
|---------|-----------|
| \(Si <= 1500\) | НОРМА |
| \(Si > 1500\) (первый раз) | ТРЕВОГА (вывод деталей) |
| \(Si > 1500\) (повторно) | Игнорируется (тревога уже зафиксирована) |

## Этап 3. Результаты работы программы

### Исходный код программы (C)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
#include <math.h>

// Функция для вычисления мощности Q по заданному X
double get_q(double x)
{
    if (x < 100) return 2.0 * x + 10;
    if (x < 200) return 1.5 * x + 60;
    return 0.8 * x + 200;
}

int main() 
{
    setlocale(LC_ALL, "RUS");

    double x;
    double q0 = 350.0;    // Целевое значение из задания
    double smax = 1500.0; // Максимальное отклонение из задания
    
    double Q[1000];       // Массив для хранения значений Q (для медианы)
    int n = 0;            // Счетчик измерений
    
    double s_current = 0; // Текущее накопленное отклонение
    int alarm_found = 0;  // Флаг первого превышения

    printf("Введите показания датчика X (любой символ для выхода):\n");

    // Ввод данных до ввода нечислового символа
    while (scanf("%lf", &x) == 1) 
    {
        Q[n] = get_q(x); // Считаем Q
        s_current += fabs(Q[n] - q0); // Считаем накопленное отклонение S
        
        printf("X=%.1f -> Q=%.1f ", x, Q[n]);

        // Проверка на ПЕРВОЕ превышение Smax
        if (s_current > smax && alarm_found == 0) 
        {
            alarm_found = 1;
            printf("[ТРЕВОГА!] Первое превышение Smax!\n");
            printf("  -> Значение Q в этот момент: %.2f\n", Q[n]);
            printf("  -> Накопленное отклонение:   %.2f\n", s_current);
            printf("  -> Обработано измерений:     %d\n", n + 1);
        } 
        else 
        {
            printf("[S=%.1f, норма]\n", s_current);
        }
        
        n++; 
    }

    if (n == 0) 
    {
        printf("Нет данных для обработки.\n");
        return 0;
    }

    // --- Статистика ---
    double sum = 0, min_q = Q[0], max_q = Q[0];

    // 1. Сумма, мин, макс
    for (int i = 0; i < n; i++) 
    {
        sum += Q[i];
        if (Q[i] < min_q) min_q = Q[i];
        if (Q[i] > max_q) max_q = Q[i];
    }
    double mean = sum / n;

    // 2. Дисперсия и СКО (Выборочная дисперсия)
    double var = 0;
    for (int i = 0; i < n; i++) 
    {
        var += (Q[i] - mean) * (Q[i] - mean);
    }
    var = (n > 1) ? var / (n - 1) : 0; 
    double std = sqrt(var);

    // 3. Медиана (сортировка пузырьком)
    for (int i = 0; i < n - 1; i++) 
    {
        for (int j = 0; j < n - 1 - i; j++) 
        {
            if (Q[j] > Q[j + 1]) 
            {
                double temp = Q[j];
                Q[j] = Q[j + 1];
                Q[j + 1] = temp;
            }
        }
    }
    
    double med;
    if (n % 2 != 0) med = Q[n / 2];
    else med = (Q[n / 2 - 1] + Q[n / 2]) / 2.0;

    // Вывод результатов
    printf("\n--- Статистика ---\n");
    printf("Среднее:             %.2f\n", mean);
    printf("Медиана:             %.2f\n", med);
    printf("Дисперсия:           %.2f\n", var);
    printf("Станд. отклонение:   %.2f\n", std);
    printf("Минимум:             %.2f\n", min_q);
    printf("Максимум:            %.2f\n", max_q);
    printf("Диапазон:            [%.2f, %.2f]\n", mean - std, mean + std);

    return 0;
}
```
